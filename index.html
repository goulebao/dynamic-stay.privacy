【重要提示】请您在使用本应用前，仔细阅读并理解本隐私政策。如您不同意本政策的任何内容，请停止使用本应用。一旦您开始使用，即视为您已同意本政策。

灵动常驻是由北京购了宝贸易有限责任公司（以下简称“我们”）为您提供的工具类应用。我们高度重视您的个人信息保护，并会严格按照法律法规的要求，以合法、正当、必要和诚信的原则处理您的个人信息。

1、我们如何收集和使用个人信息

为了向您提供灵动岛展示、广告积分、提现、用户登录及版本更新等服务，我们需要收集和使用以下信息：

  1. 账号信息：当您使用微信登录时，我们会收集您的微信openid、昵称、头像等由您授权的信息，用于创建账号和标识用户身份。
  2. 积分与提现信息：为记录您的积分获取、兑换及提现操作，我们会收集积分变动记录、提现申请记录、支付宝或微信收款账号信息（如您主动填写）。
  3. 设备与网络信息：为保障服务稳定性、安全性及广告投放效果，我们会收集设备型号、操作系统版本、网络状态、IP地址、MAC地址、OAID等设备标识信息。
  4. 应用使用信息：我们会收集应用崩溃日志、性能数据以及广告展示、点击、转化等交互数据，用于改善产品质量和广告体验。
  5. 位置信息：我们可能会在获得您授权后收集粗略或精确位置信息，用于广告定向投放及反作弊。

2、穿山甲广告SDK相关说明

本应用集成了北京巨量引擎网络技术有限公司提供的穿山甲广告SDK（com.pangle.cn:ads-sdk-pro，版本 7.6.4.2），用于广告投放、展示及效果优化。穿山甲SDK会自行收集和处理部分信息，具体说明如下：

① 设备信息
收集字段：设备品牌、型号、软件系统版本、屏幕密度、分辨率、设备语言、时区、SIM卡信息（mcc&mnc）、CPU信息、可用存储空间、OAID、Android ID、设备标识符（如GAID）等。
用途和目的：广告投放、广告监测归因及广告反作弊。

② 网络信息
收集字段：运营商信息、Wi-Fi状态、网络信号强度、IP地址、MAC地址。
用途和目的：保证网络服务有效性、广告投放及反作弊。

③ 应用信息
收集字段：应用包名、运行中的进程信息、版本号、应用前后台状态。
用途和目的：广告投放及广告反作弊。

④ 传感器信息
收集字段：加速度传感器、陀螺仪传感器、磁场传感器、线性加速度传感器、旋转矢量传感器。
用途和目的：摇一摇、扭一扭等互动广告投放及反作弊。

⑤ 广告信息
收集字段：广告展示、点击、转化等交互数据。
用途和目的：广告监测归因、投放统计分析及反作弊。

⑥ 位置信息
收集字段：精确位置信息、粗略位置信息（WiFi列表、WLAN接入点、基站）。
用途和目的：广告定向投放及反作弊（可选）。

⑦ 性能数据
收集字段：崩溃数据、性能数据。
用途和目的：减少应用崩溃，提供稳定服务。

【特别提示】本应用在初始化穿山甲SDK时已通过 TTCustomController 将应用列表（alist）获取开关设置为关闭，SDK不会主动读取您的已安装应用列表。如您在使用中遇到任何应用列表授权请求，均可选择拒绝。

穿山甲广告SDK隐私政策详见：https://www.csjplatform.com/privacy/partner

3、广告内容免责声明

广告内容由字节跳动广告SDK提供，本平台无法掌控，请自行辨别广告。若因为广告内容导致的投诉举报，由于广告内容本平台无法掌控完全由字节跳动SDK输出，均与本平台无关。本公司所扮演的角色与传统的发传单人员基本一致，区别在由于是电子传单，所以无法预知传单内容，只能依靠字节跳动的穿山甲SDK，若有违反法律法规的内容请及时告知，我们将反馈到穿山甲相关部门处理，感谢您的合作。

4、权限申请及使用说明

为保障产品功能正常运行，我们可能需要申请以下权限：

  • INTERNET / 网络访问权限：用于与服务器通信、加载广告内容。
  • ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE：用于判断网络状态，优化广告加载及请求策略。
  • READ_PHONE_STATE：用于获取设备标识信息，保障广告投放及反作弊。
  • ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION：用于广告定向投放及反作弊，仅在您授权后使用。
  • READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE：用于缓存广告素材、保存应用运行所需文件。
  • SYSTEM_ALERT_WINDOW：用于在其他应用上层显示灵动岛悬浮窗。
  • BIND_NOTIFICATION_LISTENER_SERVICE / POST_NOTIFICATIONS：用于监听通知并在灵动岛中展示通知内容。
  • FOREGROUND_SERVICE：用于保障灵动岛核心服务在后台稳定运行。
  • REQUEST_INSTALL_PACKAGES：用于应用版本更新安装。
  • 无障碍服务权限：用于实现灵动胶囊的显示与交互。
  • REQUEST_IGNORE_BATTERY_OPTIMIZATIONS：用于引导您前往系统设置，允许灵动岛后台服务稳定运行。
  • MEDIA_CONTENT_CONTROL：用于在灵动岛中展示当前播放音乐的信息及控制播放。
  • READ_CALENDAR / WRITE_CALENDAR：用于在灵动岛中展示日程提醒信息（仅在您授权后使用）。
  • GET_TASKS：用于判断应用前后台状态，优化灵动岛显示逻辑及广告请求策略。
  • EXPAND_STATUS_BAR：用于在灵动岛交互中展开或折叠系统状态栏通知区域。
  • QUERY_ALL_PACKAGES：用于在通知应用选择、分享跳转等场景查询设备已安装应用列表。

上述权限均会在需要时通过系统弹窗向您申请，您可以根据实际需求选择授予或拒绝。拒绝部分权限可能会影响相应功能的正常使用。

5、自启动与关联启动说明

为保障灵动岛核心功能（音乐播放状态展示、电量/网速信息显示、通知提醒、屏幕亮灭状态响应等）能够在系统层面被及时触发，本应用使用了系统级服务与广播监听机制。在您点击“同意”本隐私政策之前，本应用不会启用任何可能触发自启动或关联启动的服务与监听；只有在您明确同意本隐私政策后，相关功能才会按下列场景运行。

  1. 无障碍服务（灵动常驻）：本应用注册了无障碍服务，用于在其他应用上层绘制并管理灵动岛悬浮窗、响应用户交互。当您在系统设置中开启该服务后，系统可能在切换应用、屏幕点亮等场景下绑定或唤醒本服务，从而触发应用启动。该服务是实现灵动岛显示与交互的必要组件，仅在您同意隐私政策并在设置中手动开启后生效。
  2. 通知监听服务：本应用注册了通知监听服务，用于接收系统通知并在灵动岛中展示。系统可能在收到新通知时绑定该服务，从而唤醒应用进程。该服务是实现通知灵动岛提醒的必要组件，仅在您同意隐私政策后生效。
  3. 电量状态监听：为在灵动岛中实时展示当前电量百分比，本应用会动态注册系统电量变化广播（ACTION_BATTERY_CHANGED）。该广播由系统电量变化触发，仅在您同意隐私政策且开启电量显示功能后注册。
  4. 屏幕亮灭监听：为在屏幕点亮/熄灭时正确显示或隐藏灵动岛，本应用会动态注册屏幕开关广播（ACTION_SCREEN_ON / ACTION_SCREEN_OFF）。该广播仅在您同意隐私政策且灵动岛功能启用后注册。
  5. 音乐播放状态检测：为在灵动岛中展示当前音乐播放信息，本应用会通过音频管理器定时检测音乐播放状态。该检测仅在您同意隐私政策且开启音乐灵动岛功能后运行。
  6. 网络速度刷新：为在灵动岛中展示实时网速，本应用会定时读取系统流量统计信息并刷新显示。该刷新仅在您同意隐私政策且开启网速显示功能后运行。
  7. 穿山甲广告SDK的关联启动行为：本应用集成的穿山甲广告SDK（com.pangle.cn:ads-sdk-pro）在广告投放、广告归因、反作弊及任务调度过程中，可能会使用系统广播（如开机完成、网络变化、电量变化等）进行任务唤醒或关联启动。上述行为由SDK自行实现，用于保障广告正常展示与积分奖励结算，具体收集与使用规则请参见穿山甲广告SDK隐私政策：https://www.csjplatform.com/privacy/partner。
  8. 系统/第三方组件的自动唤醒：由于本应用集成了AndroidX WorkManager等系统组件及第三方SDK，系统可能为了完成后台任务调度、下载任务恢复、崩溃日志上报等目的，在特定场景下自动唤醒应用进程。该类唤醒属于系统或SDK的标准行为，不涉及未经您同意的主动自启动。

【用户控制权】若您不同意上述自启动或关联启动行为，请点击隐私政策页面下方的“不同意”并停止使用本应用；您也可以随时在手机系统设置的“应用管理”或“应用启动管理”中关闭本应用的自启动/关联启动权限，关闭后灵动岛、通知提醒、音乐/电量/网速实时展示等功能可能会受到影响或无法正常运行。

  2. 禁止违规刷取广告收益：您不得利用漏洞、作弊软件或其他不正当方式批量刷取广告积分或提现收益。一经发现，我们有权暂停或终止您的账号，并保留追究法律责任的权利。

  4. 公平使用：您应遵守国家法律法规及相关平台规则，公平、诚信地使用本应用提供的各项服务。

如您违反上述约定，我们有权依据相关规定采取限制功能、冻结积分、封禁账号等措施。

  3. 为处理提现等金融服务，与支付机构共享必要的收款信息；
  4. 在合并、收购、资产转让等情形中，我们会要求新的信息接收方继续遵守本隐私政策。

我们依照法律法规的规定，将在中华人民共和国境内收集和产生的个人信息存储于境内。我们会采取合理的技术和管理措施保护您的个人信息，防止数据遭到未经授权的访问、泄露、篡改或丢失。

一般而言，我们只会在实现本政策所述目的所必需的期限内保留您的个人信息。超出必要期限后，我们将对您的个人信息进行删除或匿名化处理，法律法规另有规定的除外。
